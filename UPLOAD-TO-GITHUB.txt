This package is prepared for the existing Cloudflare Worker project connected to GitHub.

- package.json
- src/index.js
- public/index.html
- public/styles.css
- public/app.js
- public/assets/kizazi-radio-official-logo.png
- public/assets/kizazi-radio-hero.webp
